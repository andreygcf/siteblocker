# Использование

## Установка

1. Открыть `chrome://extensions`.
2. Включить **Режим разработчика** (переключатель справа сверху).
3. **Загрузить распакованное расширение** → указать папку с `manifest.json`.
4. Открыть настройки расширения (кнопка «Подробнее» → «Параметры расширения», либо
   иконка расширения → «Настройки») и добавить первый сайт.

## Язык интерфейса

Расширение переведено на русский, английский, немецкий и французский. Язык берётся из языка
интерфейса браузера, отдельной настройки нет: для остальных языков используется английский.
Даты и названия месяцев форматируются по той же локали.

## Типы сайтов

При добавлении сайта выбирается один из двух типов — от него зависит, какой пресет стиля
применится к плашке.

| Тип | Когда выбирать | Плашка по умолчанию |
|---|---|---|
| **Трата времени** (waste) | сайт ворует время и хочется получать по этому поводу «пощёчину» | красная на весь экран, через 5 сек сворачивается в бейдж с живым таймером |
| **Статистика** (stats) | просто интересно, сколько времени уходит | небольшая полупрозрачная плашка в правом нижнем углу |

Сайт задаётся доменом — схема, `www.`, путь и порт срезаются автоматически.
Учитываются все поддомены: `youtube.com` покрывает и `m.youtube.com`, и `music.youtube.com`.
Если в списке есть и `example.com`, и `sub.example.com`, для страницы поддомена выигрывает
более конкретная запись.

## Плашка

Показывает четыре числа: время текущей сессии (крупно), сегодня, за месяц, всего.

- **Одиночный клик** — открыть страницу статистики по этому сайту в новой вкладке.
- **Двойной клик** — свернуть или развернуть плашку.
- Свёрнутое состояние запоминается на вкладку: переходы внутри сайта не разворачивают её заново.
- **Крестик** — только у плашки типа «Статистика» и только если это разрешено в настройках
  («Поведение» → «Плашку „Статистика“ можно закрыть»). Скрывает плашку до закрытия вкладки
  (переходы внутри сайта и перезагрузка её не возвращают);
  время при этом продолжает считаться. Плашку «Трата времени» закрыть нельзя — только свернуть.
- Пульсирующая точка слева означает, что счётчик идёт. Погасла и плашка поблёкла — счётчик на паузе.

## Как считается время

Счётчик идёт, когда одновременно выполняются три условия:

1. вкладка с сайтом активна,
2. окно браузера в фокусе (свернули окно или ушли в другое приложение — пауза),
3. пользователь не бездействует дольше порога (по умолчанию 60 сек; настраивается).

**Сессия** привязана к конкретной вкладке:

- переключение на другую вкладку и обратно — сессия продолжается (была на паузе);
- уход с домена в той же вкладке или закрытие вкладки — сессия обнуляется;
- перезагрузка страницы сессию сохраняет.

Накопленное время (день/месяц/всего) не теряется ни при паузе, ни при закрытии вкладки.
Несколько вкладок одного сайта не удваивают учёт — считается только активная.

## Страница статистики

Открывается кликом по плашке, кнопкой в попапе или из настроек.

- **Селектор сайта** сверху — конкретный сайт или «Все сайты» (суммарно).
- **Плитки**: сегодня, за 7 дней, за месяц, всего, в среднем в день, рекорд за день.
- **По дням** — столбчатый график с переключателем 7 / 30 / 90 дней.
- **Накопительно за текущий месяц** — линейный график нарастающим итогом.
- **Календарь** — heatmap по годам: чем насыщеннее ячейка, тем больше времени в этот день.
- **Сравнение сайтов** — горизонтальные бары за сегодня / месяц / всё время.
- **Сброс статистики** — за сегодня, за текущий месяц, всю по выбранному сайту, всю целиком.
  Каждая кнопка спрашивает подтверждение; при выборе «Все сайты» первые три кнопки действуют
  на все сайты сразу.

Наведение на столбец, точку или ячейку календаря показывает точное значение подсказкой.

## Настройки

### Отслеживаемые сайты

Добавление (поле домена + тип), переключение типа прямо в таблице, временное выключение
без потери статистики, удаление. При удалении сайта с накопленной статистикой спрашивается,
удалять ли данные: **OK** — удалить вместе со статистикой, **Отмена** — убрать только из списка.

### Стиль плашки

Два независимых пресета — «Трата времени» и «Статистика». Настраиваются:

- цвет фона и цвет текста;
- прозрачность;
- расположение: **весь экран**, **полоса у края** (сверху / снизу / слева / справа) или
  **плашка в углу** (любой из четырёх углов);
- размер (толщина полосы либо высота плашки) и размер свёрнутого бейджа;
- масштаб шрифта.

Справа — предпросмотр в развёрнутом и свёрнутом виде. Изменения применяются к уже открытым
вкладкам сразу, без перезагрузки. Кнопка «Сбросить стиль» возвращает пресет к стандартному.

### Поведение

- **Пауза после бездействия, сек** — сколько ждать без мыши и клавиатуры, прежде чем
  остановить счётчик. Минимум 15 (ограничение Chrome).
- **Полноэкранная плашка держится, сек** — сколько waste-плашка висит развёрнутой перед
  сворачиванием. `0` — сворачивать сразу.
- **Плашку «Статистика» можно закрыть** — на stats-плашке появляется крестик. Клик по нему
  убирает плашку до закрытия вкладки, время продолжает считаться.
  У сайтов типа «Трата времени» крестика нет никогда — их плашку можно только свернуть.

### Данные

- **Экспорт в JSON** — весь стейт (настройки, список сайтов, статистика) одним файлом.
- **Импорт из JSON** — полностью заменяет текущее состояние, спрашивает подтверждение.
- Кнопки сброса действуют на все сайты; сброс по одному сайту — на странице статистики.

## Попап

Клик по иконке расширения показывает время по текущему сайту (сессия, сегодня, месяц, всего)
и статус «Счётчик идёт» / «На паузе». Если сайт ещё не в списке — предлагает добавить его
как «трату» или как «статистику»; после добавления вкладка перезагружается, чтобы появилась плашка.
